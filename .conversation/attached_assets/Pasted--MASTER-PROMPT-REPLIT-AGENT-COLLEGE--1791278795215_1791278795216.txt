6. PROBLEM STATEMENT
============================================================

College transportation has several problems:

- Student bus attendance is difficult to maintain.
- Bus delays are difficult to monitor.
- Emergency situations are difficult to track.
- Bus maintenance can be missed.

- Colleges lack centralized transport analytics.

10. DATABASE SCHEMA
============================================================

Create a complete SQL file:

supabase/schema.sql

Create these tables:

------------------------------------
profiles
------------------------------------

id UUID PRIMARY KEY
full_name TEXT
email TEXT
phone TEXT
role TEXT
created_at TIMESTAMPTZ

role values:

admin
driver
student

------------------------------------
buses
------------------------------------

id UUID PRIMARY KEY
bus_number TEXT UNIQUE NOT NULL
registration_number TEXT UNIQUE NOT NULL
capacity INTEGER NOT NULL
status TEXT NOT NULL
fuel_level INTEGER DEFAULT 100
last_service_date DATE
next_service_date DATE
created_at TIMESTAMPTZ DEFAULT NOW()

Status values:

Available
On Trip
Maintenance
Inactive

------------------------------------
drivers
------------------------------------

id UUID PRIMARY KEY
profile_id UUID
phone TEXT
license_number TEXT UNIQUE
license_expiry DATE
status TEXT
created_at TIMESTAMPTZ DEFAULT NOW()

------------------------------------
students

id UUID PRIMARY KEY
profile_id UUID
roll_number TEXT UNIQUE
department TEXT
year INTEGER
phone TEXT
route_id UUID
stop_id UUID
created_at TIMESTAMPTZ DEFAULT NOW()

------------------------------------
routes
------------------------------------

id UUID PRIMARY KEY
name TEXT
start_point TEXT
end_point TEXT
distance_km DECIMAL
estimated_minutes INTEGER
created_at TIMESTAMPTZ DEFAULT NOW()

------------------------------------
route_stops
------------------------------------

id UUID PRIMARY KEY
route_id UUID
stop_name TEXT
latitude DECIMAL
longitude DECIMAL
stop_order INTEGER
created_at TIMESTAMPTZ DEFAULT NOW()

------------------------------------
trips

id UUID PRIMARY KEY
bus_id UUID

route_id UUID
status TEXT

completed_at TIMESTAMPTZ
created_at TIMESTAMPTZ DEFAULT NOW()

Status:

Scheduled
Running
Completed
Cancelled

------------------------------------
bus_locations
------------------------------------

id UUID PRIMARY KEY
trip_id UUID

longitude DECIMAL

------------------------------------
attendance

id UUID PRIMARY KEY
student_id UUID

status TEXT

------------------------------------
notifications
------------------------------------

id UUID PRIMARY KEY
user_id UUID
title TEXT
message TEXT
type TEXT
is_read BOOLEAN DEFAULT FALSE
created_at TIMESTAMPTZ DEFAULT NOW()

------------------------------------
maintenance
------------------------------------

id UUID PRIMARY KEY
